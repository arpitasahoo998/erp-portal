📖 User Manual & Documentation

👤 User Operations Guide

🧾 Daily Billing

  • Customer Search: Type a name to auto-fill address/phone for regular buyers.
  • Batch Selection: System uses FIFO to pick the oldest stock automatically.
  • Calculations: Discounts and GST are calculated in real-time.
  • PDF Invoices: Professional A4 prints with branch-specific details and digital stamps.

📦 Inventory & Stock

  • Stock Status: Real-time view of products available in your branch.
  • Dead Stock: Use the 💀 icon to remove damaged/expired items and log the reason.
  • Expiry Alerts: Monitor batch-wise expiry dates in the inventory list.

💰 Payment Collection

  • Tracking: Search for pending bills in the Payments module.
  • Installments: Record partial payments with Mode (Cash/Bank/UPI/Cheque).
  • Audit Trail: Your name is automatically recorded against every collection.

👑 Superadmin Administrative Controls

🏢 Branch Profiling

  • Compliance Setup: Configure GSTIN, FSSAI, PAN, and Address for each branch.
  • Identity: These details dynamically populate the header of all branch invoices.

📊 Monthly Analytics

  • Branch Activity: View consolidated monthly collection reports for all locations.
  • Staff Performance: Compare total money collected by different staff members.
  • Historical Data: Use filters to jump between months and years for trend analysis.

👥 User & Security

  • RBAC: Create users and assign specific module permissions (Billing, Finance, etc.).
  • Global Access: Superadmins see all data; staff are isolated to their own branch.
  • Data Reset: Clean up installment history or override totals if entries are wrong.

Need Technical Support?

For database connectivity issues or server maintenance, contact your technical administrator.
